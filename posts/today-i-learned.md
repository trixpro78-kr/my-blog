오늘은 Claude Code와 함께 이 블로그를 처음부터 만들었습니다. 프레임워크 없이 HTML, CSS, JavaScript만 쓰다 보니 세 가지가 각각 무슨 일을 하는지 또렷하게 보였습니다. 배운 내용을 짧게 정리해 둡니다.

## 한 문장으로 요약하면

| 언어 | 역할 | 비유 |
| :--- | :--- | :--- |
| HTML | 내용과 구조 | 집의 뼈대 |
| CSS | 모양과 배치 | 인테리어 |
| JavaScript | 동작과 반응 | 전기와 배선 |

## HTML — 무엇이 있는가

HTML은 페이지에 **무엇이 있는지**를 정합니다. 이 블로그의 `index.html`에는 머리말(`header`), 본문(`main`), 꼬리말(`footer`)이 있습니다.

```html
<header>…</header>
<main id="app"></main>
<footer>…</footer>
```

- `div`만 쓰는 대신 `header`, `article`, `time`처럼 **의미를 가진 태그**를 쓰면 화면 낭독기와 검색 엔진이 내용을 더 잘 이해합니다.
- `<meta name="viewport">` 한 줄이 없으면 휴대폰에서 페이지가 작게 축소되어 보입니다.

## CSS — 어떻게 보이는가

CSS는 같은 내용을 **어떻게 보여줄지**를 정합니다.

- **CSS 변수**: 색을 `--text`, `--title` 같은 이름으로 한곳에 모아 두면 다크 모드를 만들 때 값만 바꾸면 됩니다. 글 제목을 붉은색으로 바꿀 때도 변수 하나만 추가했습니다.
- **읽기 좋은 글**: 한 줄 길이(`max-width: 68ch`)와 줄 간격(`line-height: 1.75`)이 가독성에 큰 영향을 줍니다. 한글은 `word-break: keep-all`로 단어 중간에서 줄이 바뀌지 않게 했습니다.
- **반응형**: 작은 화면을 먼저 만들고 `@media (min-width: 768px)`로 큰 화면을 다듬었습니다. 긴 코드와 표는 `overflow-x: auto`로 그 안에서만 가로로 스크롤되게 했습니다.

```css
:root { --title: #c62828; }
[data-theme="dark"] { --title: #ff6b6b; }
.post-title { color: var(--title); }
```

## JavaScript — 무엇을 하는가

JavaScript는 페이지가 **움직이게** 만듭니다. 이 블로그에서는 세 가지 일을 맡았습니다.

1. **글 불러오기**: `fetch()`로 `posts/` 폴더의 마크다운 파일을 읽어 옵니다.
2. **마크다운 변환**: 직접 만든 파서가 `**굵게**` 같은 문법을 HTML 태그로 바꿉니다.
3. **화면 전환과 다크 모드**: 주소의 `#/post/...` 부분을 보고 알맞은 화면을 그리고, 버튼을 누르면 테마를 바꿔 저장합니다.

> 사용자가 쓴 글을 HTML로 바꿀 때는 먼저 `<`, `>` 같은 문자를 이스케이프해야 합니다. 그렇지 않으면 글 안의 `<script>`가 실제로 실행될 수 있습니다.

## 오늘의 깨달음

- 세 언어는 **역할이 분명히 나뉘어** 있어서, 고칠 부분이 어디인지 금방 찾을 수 있습니다. 색을 바꾸려면 CSS만, 동작을 바꾸려면 JavaScript만 보면 됩니다.
- `fetch()`는 `file://`로 연 페이지에서는 동작하지 않아서 `python3 -m http.server` 같은 로컬 서버가 필요합니다.
- CSS를 고쳤는데 화면이 그대로라면 브라우저 **캐시**를 의심하고 강력 새로고침(⌘+Shift+R)을 해 봅니다.
